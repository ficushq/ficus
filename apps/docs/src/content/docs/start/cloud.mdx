Ficus Cloud runs your Ficus instance for you. Your Cloud account manages instances and
billing; you sign in to the instance itself to chat with agents and manage work.

## Sign in to your account

<ModeContent mode="cloud">

Open the Cloud account page supplied with your access. Enter your email, choose
**Send code**, then enter the emailed code and choose **Verify**. You can create
a passkey for future account sign-ins or choose **Skip for now**. If you already
have an account passkey, choose **Use a passkey instead**.

If someone has invited you to an existing Ficus instance, open their instance link
and follow its account-registration instructions. You do not need to create a
second instance to join their team.

</ModeContent>

<ModeContent mode="self-hosted">

For an instance you operate yourself, follow [self-hosted setup](/start/self-host/).
Cloud account checkout is separate from installing and signing in to your own
server.

</ModeContent>

## Create or open an instance

<ModeContent mode="cloud">

1. From your account, open an existing instance or choose **+ New instance** to
   start the **Choose your instance** flow.
2. For a new instance, select an available plan and capacity, then enter the
   subdomain you want. Wait for the availability check and resolve any name error.
3. Choose **Continue to checkout** and review the terms and amount shown there.
4. After checkout, follow **Setting up your instance**. Complete any additional
   setup input requested by that page. Progress updates as setup advances.
5. When **Your instance is ready** appears, use its **Open** link.

Available plans and capacity are shown in your account. A payment confirmation
can take time to reach the instance page; use its recheck action if offered. If
setup reports a failure, follow the recovery action on that page rather than
creating another instance to retry the same purchase.

</ModeContent>

<ModeContent mode="self-hosted">

Open the URL reported by your installation. Use the server's initial setup flow
to create the first administrator, then continue with the same workspace setup
below.

</ModeContent>

## Set up your workspace

The first instance account establishes its administrator. Follow the instance's
passkey registration prompt. A Cloud account passkey and an instance passkey
belong to their respective sign-in pages; creating one does not register the other.

On the instance's **Get started** page:

1. **Connect an AI provider.** Agents need a working model account before they can
   run. Follow [model setup](/configure/models/) for the available authentication
   choices.
2. **Connect GitHub** if your first task needs repository access. Follow
   [GitHub setup](/connect/github/) and choose the repositories the App can access.
   You can skip this for work that does not use GitHub.
3. **Create your first squad.** Give the squad a purpose and a concrete first
   request. Follow [your first task](/start/first-task/) for an example.

You can return to settings later to invite teammates, connect a chat channel,
or add other tools. To work conversationally with Ficus, continue with
[the assistant](/use/assistant/).

## If you cannot continue

An unavailable setting may require an administrator. Ask the instance owner for
access rather than creating a new connection under an unrelated account. For
instance configuration choices, see [configuration](/reference/configuration/).
